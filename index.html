隐私政策

更新日期：2026 年 11 月 7 日 · 适用版本：1.0.x

只在本机匹配和改写受支持的商店页面地址。
不向开发者收集或上传浏览数据。

1. 适用范围与单一用途

本政策适用于“商店 CDN 助手（非官方） / Store CDN Helper (Unofficial)”1.0.x。扩展的单一用途，是为受支持的 Steam 商店浏览页面自动添加或替换 _cdn=china_eccdnx，并提供启用或暂停开关。本扩展与 Valve、Steam 或 CDN 服务商无关联。

2. 处理哪些信息

扩展不向开发者收集或上传个人信息、浏览记录、账户信息、密码、Cookie、支付信息或网页正文。为实现核心功能，浏览器会在本地处理下列信息：

信息用途和处理方式保留与共享
符合规则的页面地址及查询参数由浏览器原生 declarativeNetRequest 引擎本地匹配，仅变换 CDN 选择参数。网址可能包含搜索词或语言等偏好；扩展脚本不读取或记录这些网址。不建立访问日志，不保存访问历史，不上传到开发者服务器。
启用或暂停状态以浏览器本机动态规则是否启用的形式保存，用于保留用户选择。保留至用户改变设置或卸载扩展；不使用云同步，不共享。

3. 权限与请求范围

仅申请 declarativeNetRequestWithHostAccess 以及 https://store.steampowered.com/*。前者用于创建和切换本地请求规则，后者允许在指定站点执行同源导航改写。

规则仅处理列入范围的顶层 GET 浏览页面。登录、账户、购物车、结账、API 等路径不在规则范围内；不处理 POST、iframe、XHR、图片、脚本或视频资源请求。不申请所有网站、Cookie、浏览历史、标签页列表、代理或 DNS 配置权限。

4. 传输、第三方与有限使用

扩展没有开发者后台、遥测、统计分析、广告、远程配置或远程托管代码。不会出售、出租或分享用户数据，不用于广告、用户画像、信用评估或与单一用途无关的目的。开发者不会人工查看用户浏览数据。

URL 改写保持原有 HTTPS 和 Steam 商店域名。用户正常访问 Steam 时，浏览器仍会按网站行为将请求发送给 Valve 及该网页使用的资源服务；这些网站的隐私政策适用于相应网站请求。这不代表扩展向开发者上传数据。

本扩展对信息的使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求，仅限上述公开说明的单一用途。

5. 安全、保存与删除

扩展不导入根证书，不解密 HTTPS，不关闭证书验证，不修改浏览器代理或 DNS。用户可在弹窗暂停规则，或在浏览器扩展设置中禁用、撤销站点权限或卸载本扩展。

卸载后浏览器会清除该扩展的动态规则。暂停不会主动删除已打开网址中的 CDN 参数；需恢复网站默认选择时，可暂停后使用不带参数的网址重新访问。浏览器自身保存的网站历史及 Steam 自己保存的信息，不由本扩展管理。

由于开发者没有持有上述访问数据，无法向用户导出或删除开发者服务器上的访问记录；这类记录并不存在。

6. 本政策网页

本政策页面本身不包含统计分析、广告、第三方字体、跟踪脚本或数据提交表单。提供本页的托管服务商可能为网页交付和安全处理常规连接信息（例如 IP 地址和请求时间），以其自身服务条款和隐私政策为准；这与扩展的本地规则处理相互独立。

7. 变更与联系

如果扩展的数据处理方式变化，将同步更新本政策、商店声明及必要的产品内说明，并遵循浏览器的权限和披露要求。

发布者为本扩展商店详情页显示的独立发布者。如有隐私问题，请使用相应 Chrome Web Store 或 Edge Add-ons 详情页列出的开发者联系渠道。

Privacy policy

Last updated: 7 November 2026 · Versions: 1.0.x

Supported Store navigations are matched and rewritten locally.
No browsing data is collected by or uploaded to the developer.

1. Scope and single purpose

This policy covers Store CDN Helper (Unofficial), versions 1.0.x. Its single purpose is to add or replace _cdn=china_eccdnx on supported Steam Store browsing navigations, with an enable/pause control. It is not affiliated with Valve, Steam or a CDN provider.

2. Information processed

No personal information, browsing history, account information, passwords, cookies, payment information or page content is collected by or uploaded to the developer. To provide the feature, the browser locally processes:

  • Matching page URLs and query parameters: the native declarativeNetRequest engine matches the navigation and changes only the CDN preference. URLs may include search terms or language preferences. Extension scripts do not read or log those URLs. No browsing log or history database is created.
  • The enable/pause preference: retained locally as the presence or absence of extension dynamic rules until the user changes it or uninstalls the extension. It is not cloud-synchronized or shared.

3. Permissions and request scope

The extension requests only declarativeNetRequestWithHostAccess and host access to https://store.steampowered.com/*. These enable creation and control of local same-origin navigation rules.

Rules cover listed top-level GET browsing paths. Login, account, cart, checkout and API paths are outside scope. POST, iframe, XHR, image, script and video subresource requests are not modified. The extension does not request all-site, cookie, history, tab-list, proxy or DNS configuration permissions.

4. Transfers, third parties and Limited Use

There is no developer backend, telemetry, analytics, advertising, remote configuration or remotely hosted code. User data is not sold, rented or shared, and is not used for advertising, profiling, credit assessment or purposes unrelated to the stated feature. The developer does not have human access to users’ browsing data.

Rewriting retains HTTPS and the original Steam Store origin. Normal visits to Steam still make website requests to Valve and services used by its pages. Those websites’ privacy policies apply to those requests. This is not an upload of data to the extension developer.

The extension’s use of information complies with the Chrome Web Store User Data Policy, including Limited Use requirements, and is limited to the disclosed single purpose.

5. Security, retention and deletion

The extension does not install root certificates, decrypt HTTPS, disable certificate verification, or change proxy or DNS settings. Users may pause the rules in the popup or disable, revoke site access to, or uninstall the extension through browser settings.

Uninstalling removes its dynamic rules. Pausing does not remove parameters from already-open URLs; to restore the website’s default preference, pause and reopen a URL without the parameter. Ordinary browser history and information retained by Steam are not managed by this extension.

Because the developer holds no such browsing records, there is no developer-side browsing dataset to export or delete.

6. This policy website

This page has no analytics, advertising, third-party fonts, tracking scripts or data-submission forms. The hosting provider may process ordinary connection information, such as IP addresses and request times, to deliver and secure this page, under its own terms and privacy policy. That is separate from the extension’s local rule processing.

7. Changes and contact

If data practices change, this policy, store disclosures and necessary in-product notices will be updated in accordance with applicable browser disclosure and permission requirements.

The publisher is the independent publisher named on the extension’s store listing. For privacy inquiries, use the developer contact channel listed on the corresponding Chrome Web Store or Edge Add-ons page.

Independent browser extension. Not affiliated with Valve, Steam or any CDN provider.
