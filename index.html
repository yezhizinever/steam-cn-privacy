Steam 商店 CN 浏览：隐私政策

更新日期：2026年11月7日

本政策适用于“Steam 商店 CN 浏览”浏览器扩展1.0.0、1.0.1版本。

扩展用途

本扩展仅在指定的 Steam 商店浏览页面导航中添加或替换 cc=cn 查询参数，保留其他查询参数。它不修改账号商店国家，不保证特定 CDN 的分配结果。

数据处理

扩展使用浏览器本地的声明式网络规则，对 https://store.steampowered.com/ 下符合条件的顶层 GET 页面导航进行 URL 匹配和参数调整。扩展脚本不记录、保存或上传访问网址、搜索词或其他查询参数，不读取页面正文、Cookie、账号标识、密码或支付信息，不访问浏览历史。

本扩展没有开发者服务器、统计分析、广告或错误遥测服务，不向开发者或其他第三方上传用户数据，不出售用户数据，不将数据用于广告或其他与上述功能无关的用途。

经过调整的商店网址仍由浏览器正常发送给 Steam。Steam 网站自身的请求、Cookie 和数据处理受 Steam 的相关政策约束，本扩展不会阻止这些正常网站行为。

本地设置

浏览器会在本地保存扩展规则的启用或暂停状态，以便后续浏览继续使用用户选择。扩展没有单独建立个人数据数据库或日志，也不通过开发者服务同步设置。

权限用途

- declarativeNetRequestWithHostAccess：用于通过声明式规则调整符合条件的商店浏览页面 URL。

- https://store.steampowered.com/*：限定上述规则可以作用的站点范围。规则不处理登录、账号、购物车、结算、支付页面或接口请求，也不处理其他网站。

扩展的脚本、样式和规则随安装包提供，不加载或执行远程 JavaScript 或 WebAssembly 代码。

用户控制

用户可通过扩展弹窗暂停或恢复自动补参，也可在浏览器扩展管理页禁用或卸载扩展。暂停后，当前网址中已有的 cc=cn 不会自动移除；需要恢复默认参数时，可自行删除该参数并刷新页面。

政策遵循与更新

本扩展对信息的处理遵守 Chrome Web Store 用户数据政策，包括适用的 Limited Use（有限使用）要求。若未来功能或数据处理行为发生变化，将同步更新此政策及商店披露。

隐私问题可通过 Chrome Web Store 中本扩展商品页面展示的开发者联系渠道反馈。
